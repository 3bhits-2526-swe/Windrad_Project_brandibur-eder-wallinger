Teammitglieder: Bogdan Brandibur - Tobias Wallinger - Luca Eder

The Unity project should display multiple 3D wind turbines that rotate. Their rotation speed depends on the simulated wind speed. The wind speed is based on real weather data from various cities around the world. The weather data is retrieved from a weather API, and the user can select a city from a predefined list by pressing the respective key.
